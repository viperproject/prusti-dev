Name mangling

Viper identifiers derived from Rust items are built from the item's full definition path, so that items with the same name in different modules do not collide. The path is then sanitized, since Viper identifiers may not contain most of the punctuation a Rust path does.

For example, the predicate encoding std::ops::Range is named:

predicate p_std$col$$col$ops$col$$col$Range(self) {
  ...
}

which is the sanitized form of p_std::ops::Range.

The SHORT_VIPER_NAMES flag replaces the definition path with the item's short name (here, p_Range), which is more readable when inspecting generated Viper by hand. Sanitization still applies. Short names are not unique, so enabling the flag may result in errors due to name collisions.
