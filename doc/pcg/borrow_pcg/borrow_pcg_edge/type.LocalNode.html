pub type LocalNode<'tcx, P = Place<'tcx>> = PcgNode<'tcx, MaybeLabelledPlace<'tcx, P>, MaybeLabelledPlace<'tcx, P>>;
Expand description

Any node in the PCG that is “local” in the sense that it can be named by referring to a (potentially labelled) place, i.e. any node with an associated place. This excludes nodes that refer to remote places or constants.
