pub fn into_singleton_coupled_edge(self) -> PcgCoupledEdgeKind<'tcx>

Creates a singleton coupling hyperedge from this edge.

This is presumably NOT what you want, as there is no coupling logic involved. Instead, consider [BorrowsGraph::coupling_results]. However, Prusti is currently using this function for loops.
