Struct LifetimeProjection 

Source 
pub struct LifetimeProjection<'tcx, Base = PcgLifetimeProjectionBase<'tcx>, Kind = Region> { /* private fields */ }
Expand description

A lifetime projection b↓r, where b is a base and r is a region (or generalized lifetime).

The Kind parameter distinguishes whether the region index refers to only the regions of a type (Region, the default) or to the full generalized lifetime list including type parameters (Generalized).
