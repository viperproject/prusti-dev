clean_if_stale_specs 🔒
Runs cargo clean on cargo_target if the .specs files in it were written with a different specs format version (or by a Prusti version before the version was recorded). Cargo would not rebuild them by itself, since it does not know that Prusti changed, and Prusti could not read them.
copy_exported_specs 🔒
Copy specs from ‘{cargo_target}//deps/.specs’ (Cargo’s classic layout) and ‘{cargo_target}//build///out/.specs’ (Cargo’s newer build-dir layout, which no longer populates deps/) to ‘{cargo_target}//.specs’.
