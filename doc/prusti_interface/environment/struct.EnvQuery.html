pub fn is_function_in_crate( self, caller_def_id: impl IntoParam<ProcedureDefId>, called_def_id: impl IntoParam<ProcedureDefId>, call_substs: GenericArgsRef<'tcx>, crate_name: &'tcx str, ) -> bool

Given the called_def_id of a function, called from caller_def_id, and some substitutions call_substs applied for that call, returns true if the call is to a function in the specified crate crate_name. A trait method call is attributed to the crate of the impl it relies on (e.g. PartialOrd::le on Int belongs to prusti_contracts, even though the default le body lives in core); other calls, and trait calls whose impl is unknown (e.g. a generic Self), to the crate of the called definition itself.
