PRUSTI_LIBS
Determines which crates in ./prusti-contracts have their specs re-exported for prusti-rustc.
SPECS_FORMAT_VERSION
Version of the .specs file format, written after SPECS_MAGIC. Bump this whenever the encoding in prusti-interface/src/specs/{encoder,decoder}.rs or any of the serialized types change: cargo-prusti then cleans its target directory, since cargo does not rebuild dependencies (and hence their .specs files) when only Prusti changes.
SPECS_FORMAT_VERSION_STAMP
Name of the file in cargo-prusti’s target directory that records the SPECS_FORMAT_VERSION of the .specs files in it.
SPECS_MAGIC
Magic bytes at the start of every .specs file.
