pub fn short_viper_names() -> bool
Expand description

When enabled, Viper identifiers derived from Rust items use the item’s short name (e.g. Foo) instead of its full definition path (e.g. my_crate::module::Foo).

Note: Short names are not unique across modules and crates, so this is may result in invalid programs being generated because of name collisions. It exists to make generated Viper code readable while debugging the encoder.
